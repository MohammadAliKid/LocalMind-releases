Sync help and troubleshooting

How Google Drive pairing codes work, what to do when you can't find yours, how to switch Google accounts, and how to get unstuck when Android folder sync stops responding.

Never share your pairing code. Nobody from LocalMind will ever ask for it. Don't put it in a bug report, screenshot, email or support issue. LocalMind removes pairing codes from bug reports automatically, but keep it out of them anyway.

The pairing code is your library's key

When you set up Google Drive sync, LocalMind creates a pairing code that starts with LMD1-. It holds the key that encrypts everything LocalMind stores in Drive. Google only ever receives encrypted files in a hidden LocalMind folder; it never sees the code.

  • Save it somewhere safe, such as a password manager or a printed copy kept at home. LocalMind asks you to confirm this when you set up.
  • Google sign-in can't recover it. Signing in proves who you are to Google. It doesn't give anyone the key, and LocalMind keeps no copy on any server.
  • Every device that syncs keeps the code in its own protected storage (Windows DPAPI or Android Keystore), so a connected device can always show it again.

Add another device

  1. On a device that already syncs, open Settings → Sync → Google Drive → Show pairing code.
  2. On the new device, sign in to the same Google account. LocalMind sees the existing library and asks for its code.
  3. Type the code or scan its QR code, then choose Join library. Notes already on the new device are kept and added to the library.

If this device previously synced with a different library, LocalMind asks before adding its notes to this one. Two libraries are never merged without your confirmation.

From version 0.6.10 the library downloads several files at a time, so joining and catching up are faster (uploads stay one at a time). From version 0.6.9 the code is checked in a few seconds. The library then downloads in the background: Settings shows Downloading your library… N of M files with Cancel recovery, and you can close Settings meanwhile. If LocalMind closes or the connection drops, Settings offers Resume, which continues where it stopped without downloading again what already arrived. Several devices can join with the same code, one after another or at the same time.

Can't find your pairing code?

Choose Can't find your pairing code? under the code field. Try these in order:

1. Another device is still connected

Any PC or phone that still syncs with this Google account has the code. Open Settings → Sync → Google Drive → Show pairing code there and copy or scan it. If the device you're using synced with this library before, it may still remember the code: LocalMind then offers Reconnect without asking for it.

2. You saved a copy

Look in your password manager, notes or printed copies for a code starting with LMD1-. A code only opens the library in the Google account it was made for. If LocalMind says no library matches, check that you're signed in to the right account; the signed-in account is shown at the top of the Google Drive section.

3. It's lost on every device and every copy

Then nobody can open that library: not LocalMind, not Google, and not by confirming your email address. That is exactly what keeps it private. See the next section for how to start again.

Starting a new library when the code is lost

This does not recover the old library. It creates a new, empty encrypted library and fills it from the notes on the device you're using. Notes that existed only in the old library are lost.

  1. Keep your local notes. They stay on your device throughout. For extra safety, create a backup first (LocalMind offers Create a backup now in the assistant).
  2. Make sure no device still syncs the old library. If one does, it has the code: use it instead (path 1 above).
  3. Confirm you understand that deleting LocalMind's hidden Drive data permanently deletes the old encrypted library. LocalMind keeps the next step locked until you do.
  4. Delete only LocalMind's hidden data in Google Drive on the web: open Google Drive → Settings → Manage apps, find LocalMind, then choose Options → Delete hidden app data. Your other Drive files aren't affected. Google's wording can change slightly.
  5. Back in LocalMind, choose I've deleted it, check again, then Set up Google Drive sync. Save the new pairing code this time.

LocalMind never deletes your Drive data by itself, and a reset never touches other Google accounts.

Switching Google accounts

  • Before you've paired, use Use another Google account or Sign out in the Google Drive section. Google shows its account chooser.
  • While Drive sync is on, Use another Google account… first disconnects sync on this device. Your notes stay, the library stays in the original account for your other devices, and this device keeps that library's code.
  • Going back to the original account later: sign in with it again and choose Reconnect. No code needed.
  • Changes that hadn't uploaded yet stay on this device and upload when you reconnect to their library.
  • LocalMind refuses to sync a library into a different Google account than the one it belongs to, so a wrong account choice can't copy your library somewhere unexpected.

Android folder sync (Syncthing) is stuck

LocalMind 0.6.8 fixes the hang where folder sync could stop responding and couldn't be turned off. If the shared folder or the app that provides it stops answering:

  • Stop syncing appears while a round is running and always responds. It ends the current round; sync stays on and tries again later.
  • Turn off sync also always responds, even while the folder hangs. Your notes, waiting changes and this phone's sync identity are kept, so turning sync on again continues where it stopped.
  • Every folder operation has a time limit. Android can't always cancel a stuck request to another app's storage, so LocalMind stops waiting, reports “The sync folder stopped responding”, and retries later. A request that finishes late is ignored and can't overwrite newer files.
  • “LocalMind no longer has access to the sync folder”: Android or the file-sync app withdrew permission (for example after reinstalling it). Choose Choose Sync Folder and pick the same folder again.
  • “Some incoming sync files are incomplete”: another device's changes are still arriving. They're imported on a later round, never half-written.
  • LocalMind's Stop, Pause and Turn off don't control the separate Syncthing app. To stop file transfers between your devices, pause the folder in that app.

You never need to clear LocalMind's app data, delete sync files or reset anything to recover from a stuck sync. If a problem continues, use Settings → Report a Bug in LocalMind for Windows; it removes pairing codes, keys and file paths before sending.
